# Smart-Trash-Can-
This project is an intelligent waste management system developed with Raspberry Pi, featuring contactless lid control and real-time fill level monitoring. By utilizing ultrasonic sensors to detect nearby objects, the system automatically opens the lid via a servo motor while simultaneously reporting the trash can's occupancy status through a color-coded RGB LED (Green for empty, Yellow for warning, and Red for full).

Türkçe Açıklama:

Bu proje, Raspberry Pi kullanılarak geliştirilmiş, temassız kapak kontrolü ve gerçek zamanlı doluluk oranı takibi yapabilen akıllı bir çöp kutusu sistemidir. Ultrasonik sensörler aracılığıyla yaklaşan bir objeyi algıladığında servo motor yardımıyla kapağı otomatik olarak açan sistem, aynı zamanda kutu içindeki doluluk seviyesini bir RGB LED üzerinden görsel olarak (Boş için Yeşil, Orta için Sarı, Dolu için Kırmızı) kullanıcıya anlık olarak raporlamaktadır.
